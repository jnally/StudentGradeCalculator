# Student Grade Calculator

## Description
The Student Grade Calculator is an object-oriented C# console application that demonstrates inheritance, encapsulation, and polymorphism. It calculates final averages and assigns letter grades based on distinct grading scales for Undergraduate and Graduate students.

## How to Run
1. Clone this repository or download the source code to your local machine.
2. Open the StudentGradeCalculator.sln solution file using Visual Studio.
3. Ensure the project is set to run as a Console Application.
4. Click the Start button in the Visual Studio toolbar to build and launch the application.
5. Follow the on-screen prompts to enter a student's name, their student type (Undergraduate or Graduate), and their exam scores.
